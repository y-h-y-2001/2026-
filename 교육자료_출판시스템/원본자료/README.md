# 원본 자료

여기에 두는 파일은 나중에 만든 문항이 어디서 왔는지 돌아가 확인할 수 있게 하는 원본입니다.

| 폴더 | 넣는 것 |
| --- | --- |
| 교육과정 | 교육부가 고시한 교육과정 파일. 지금 들어 있는 한글 파일은 교육부 게시판에서 받은 것입니다. |
| 검정공고 | 한국교육과정평가원이 발표한 검정 합격 공고. 교과서 이름이 맞는지 보는 서류입니다. |
| 교과서 | 교사가 이미 가지고 있는 교과서 PDF만 둡니다. 이 폴더의 PDF는 저장소에 올라가지 않습니다. |
| 입고 | 방금 받은 파일을 잠시 두는 곳입니다. |
| 추출텍스트 | PDF에서 뽑은 글자. 저장소에 올라가지 않습니다. |

교과서 파일은 학교가 구입했거나 교사가 정당한 절차로 받은 것만 넣습니다. 다른 사람이 올린 파일을 내려받아 넣지 않습니다.
