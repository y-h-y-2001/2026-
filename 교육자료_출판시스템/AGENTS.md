# 이 폴더에서 일하는 AI에게

사용자는 중·고등학교 사회·역사 교사다. 개발 용어보다 하는 일을 먼저 말한다.

## 반드시 지킬 것

1. 성취기준 문장, 성취기준 코드, 교과서 서명, 발행사, 저자, 검정번호는 원문에서 읽은 것만 넣는다. 기억이나 뉴스 기사로 채우지 않는다.
2. 교과서를 인터넷에서 내려받거나, 본문을 데이터베이스·원고·저장소에 복사하지 않는다. 교사가 이미 가지고 있는 파일을 연결하는 것만 한다.
3. 문항, 해설, 비교 메모에는 성취기준 코드와 출처 ID가 있어야 한다. 둘 중 하나라도 데이터베이스에 없으면 저장하지 않는다.
4. 확인하지 못한 칸은 비워 둔다. 빈칸을 그럴듯한 이름으로 채우지 않는다.
5. 이미 있는 파일은 삭제하거나 덮어쓰지 않는다. 데이터베이스를 다시 만들 때는 기존 파일을 `출판시스템_이전_날짜.sqlite`로 옮긴다.
6. 관리자 권한이 필요하거나, 컴퓨터 보안 설정을 바꾸는 작업은 실행하지 말고 교사에게 먼저 묻는다.
7. 교사 메모가 교과서 문장을 길게 옮긴 것이면 저장하지 말고, 짧게 다시 적도록 안내한다.

## 원문 위치

- 교육과정: `원본자료/교육과정/[별책7] 사회과 교육과정.hwp`
- 교과서 서지: `원본자료/검정공고/`의 2024년 합격 공고 PDF
- 만든 결과: `데이터베이스/출판시스템.sqlite`

교육과정 파일을 바꾸면 `프로그램/데이터베이스_만들기.py`로 다시 읽고, 성취기준 수가 크게 줄면 저장하지 말고 멈춘다.

## 하지 말 것

- 출판사 홈페이지나 교과서 PDF를 자동으로 수집하는 코드를 추가하지 않는다.
- 샘플 문항을 실제 수업 자료인 것처럼 설명하지 않는다.
- 이 저장소의 상위 `README.md`, `index.html`을 수정하지 않는다.
