# 교육자료 출판 시스템

중·고등학교 사회·역사 수업 자료를, 2022 개정 교육과정의 성취기준과 확인된 출처에 붙여 만들고 검수하는 폴더입니다.

이 폴더에는 교과서 본문이 없습니다. 교육부 고시문에서 읽은 성취기준과, 한국교육과정평가원 검정 합격 공고에서 읽은 책 이름·발행사·검정번호만 들어 있습니다.

## 내 문서 폴더로 옮기기

저장소를 받은 뒤, Mac의 터미널에서 저장소 폴더로 이동해 아래를 실행합니다. `문서` 폴더에 같은 이름이 이미 있으면 복사하지 않고 멈춥니다.

```bash
if [ -e "$HOME/Documents/교육자료_출판시스템" ]; then
  echo "이미 문서 폴더에 같은 이름이 있어 복사하지 않았습니다."
else
  cp -R "교육자료_출판시스템" "$HOME/Documents/교육자료_출판시스템"
fi
```

## 시작

1. `시작하기.command`를 더블클릭합니다.
2. 처음에는 이 폴더 안에만 파이썬 환경을 만들고 필요한 프로그램을 설치합니다. 컴퓨터 전체 설정을 바꾸지 않습니다.
3. 번호 메뉴가 나오면 숫자를 입력합니다.

설치가 관리자 암호를 묻거나, 글자 인식(OCR)을 위해 Tesseract를 설치해야 하면 그 단계에서 멈추고 내용을 확인한 뒤 진행하면 됩니다. OCR이 없어도 성취기준 검색, PDF 글자 추출, 중복 검사, 원고 만들기는 동작합니다.

## 메뉴

| 번호 | 하는 일 |
| --- | --- |
| 1 | 성취기준 수, 등록된 교과서 서지 수, 원문 파일을 연결한 책 수를 보여 줍니다. |
| 2 | 성취기준 코드나 문장에 들어 있는 말로 찾습니다. |
| 3 | 글자가 들어 있는 PDF에서 쪽마다 글자를 뽑습니다. 결과는 `원본자료/추출텍스트`에 저장됩니다. |
| 4 | 스캔 PDF를 읽습니다. Mac에 Tesseract와 한글 언어 파일이 있어야 합니다. |
| 5 | 저장한 문항 가운데 같은 것, 거의 같은 것을 찾습니다. |
| 6 | 학생용 워드 파일과 교사용 워드 파일을 `산출물`에 만듭니다. 학생용에는 정답을 넣지 않습니다. |
| 7 | 내가 가진 교과서 PDF를 검정번호와 연결합니다. 공고에 없는 번호는 연결하지 않습니다. |
| 8 | 어떤 성취기준을 어떤 교과서가 어떻게 다루는지, 내 메모를 남깁니다. |
| 9 | 문항을 직접 넣습니다. 데이터베이스에 있는 성취기준 코드가 있어야 저장됩니다. |

## 지금 들어 있는 자료

- 성취기준: 교육부 고시 제2022-33호 [별책 7] 사회과 교육과정 한글 파일에서 414개를 읽었습니다. 초등학교 사회, 중학교 사회·역사, 고등학교 한국사·통합사회와 사회·역사 선택 과목이 포함됩니다.
- 교과서 서지: 2024년 8월 30일 검정 합격 공고에서 사회·역사 관련 도서 87종을 골랐습니다. 중학교 역사 ①은 7종, 고등학교 한국사1은 9종입니다. 발행사는 13곳입니다.
- 모든 교과서 행은 `본문 미확보`입니다. 쪽의 문장, 사진, 활동 자료는 들어 있지 않습니다.
- `샘플` 폴더의 문항 6개는 프로그램 점검용으로 직접 쓴 문장입니다. 수업 자료가 아닙니다.

엑셀에서 보려면 `데이터베이스/성취기준.csv`와 `데이터베이스/교과서_서지.csv`를 엽니다.

## 자료를 더 넣는 순서

1. 학교에서 선정한 교과서 PDF를 준비합니다.
2. 메뉴 1번이나 CSV에서 그 책의 검정번호를 확인합니다.
3. 메뉴 7번에 검정번호와 파일 경로를 입력합니다.
4. 메뉴 8번에 성취기준 코드, 검정번호, 쪽, 짧은 메모를 적습니다. 교과서 문단을 통째로 붙이지 않습니다.
5. 메뉴 9번으로 문항을 넣습니다.
6. 메뉴 5번으로 겹치는 문항을 확인합니다.
7. 메뉴 6번으로 학생용·교사용 원고를 만듭니다.

교사용 원고에는 정답, 해설, 성취기준 문장, 교육부 고시 번호, 문항 출처가 함께 들어갑니다.

## 글자 인식이 필요할 때

스캔본은 글자 층이 없을 수 있습니다. 메뉴 3번 결과에 `글자 층이 없습니다`라고 나오면 메뉴 4번을 씁니다. 그 전에 Mac 터미널에서 다음을 실행합니다.

```bash
brew install tesseract tesseract-lang
```

Homebrew 설치가 관리자 권한을 요구하면, 화면에 나온 내용을 확인한 뒤에만 진행합니다.

## 다시 만들지 않아도 되는 것

교육과정 한글 파일이나 합격 공고 PDF를 새 파일로 바꾸었다면 `프로그램/데이터베이스_만들기.py`를 실행합니다. 기존 데이터베이스는 지우지 않고 `데이터베이스/출판시스템_이전_날짜.sqlite`로 옮겨 둡니다.

## 확인된 한계

- 2024년 8월 16일 국가교육위원회 고시 제2024-3호가 2022-33호를 일부개정했습니다. 사회과 별책 7의 개정 파일은 이 폴더에 없습니다. 성취기준 문장은 2023-11-13 시각의 교육부 게시 파일 기준입니다.
- 2025년과 2026년 합격 공고에는 중·고 사회·역사 교과서가 없어, 그 공고의 다른 과목은 넣지 않았습니다.
- 대표 저자 칸을 표에서 읽지 못한 책은 저자 칸이 비어 있습니다. 빈칸은 오류가 아니라 확인하지 못했다는 표시입니다.
